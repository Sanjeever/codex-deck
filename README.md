# Codex Deck

Codex Deck 是管理 Codex CLI 多账号、套餐额度和重置卡的桌面应用。后端使用 Go 和 Wails v2，前端使用 React 19、TypeScript、HeroUI v3 和 Tailwind CSS v4。

![Codex Deck 账号列表与操作菜单](docs/screenshots/accounts.png)

## 功能

- 浏览器 OAuth 登录、取消登录和重新登录，按用户与工作区身份区分账号。
- 启动、刷新及本地认证文件变化时同步 Codex CLI 当前 ChatGPT 账号，自动导入新账号并更新已有账号凭据。
- 查看账号、编辑别名和删除非当前账号，支持搜索、当前账号置顶和剩余额度排序。
- 隐私模式隐藏邮箱与工作区 ID，包含菜单标签、提示和恢复预览。
- 切换 Codex CLI 账号，按实际认证文件标记当前账号。
- 查看套餐、5H 和 Weekly 剩余额度及本地时区恢复时间，查询失败时保留缓存。
- Go 后台自动刷新用量，额度恢复时提前查询；用户操作可中断自动查询。
- 区分认证失效和临时请求错误，失效账号暂停自动请求，可直接重新登录。
- 可选低额度桌面通知，默认关闭，同一额度窗口只提醒一次。
- 查询重置卡数量、状态和到期时间，确认后使用；结果未确定时沿用原请求标识重试。
- WebDAV 后台自动备份与手动备份，检测远端版本冲突，确认后覆盖或整体恢复。
- 恢复预览展示远端更新时间及新增、移除账号。
- 单实例运行、再次启动唤起窗口、记住窗口尺寸与位置，支持常用快捷键。
- 启动时驻留系统托盘或菜单栏，关闭窗口后继续运行，通过托盘菜单显示窗口或退出。
- 可选开机自启动，默认关闭，当前用户登录桌面后隐藏启动并驻留托盘。

主窗口采用账号表格，设置通过对话框打开，主题跟随系统。所有业务 HTTP 请求由 Go 发起，前端通过 Wails 调用后端。

## 开发与构建

开发环境使用 Go 1.23、Node.js 26、pnpm 11.20.0 和 Wails CLI v2.12.0。macOS 需要 Xcode Command Line Tools，其他平台依赖见 [Wails 安装文档](https://wails.io/docs/gettingstarted/installation/)。

在仓库根目录启动开发环境。

```sh
wails dev
```

构建桌面应用。

```sh
wails build -clean
```

Wails 会通过 pnpm 安装依赖，执行 TypeScript 检查并构建前端。macOS 构建产物为 `build/bin/codex-deck.app`，可双击打开或执行下面命令。

```sh
open build/bin/codex-deck.app
```

单独构建前端与运行检查。

```sh
pnpm --dir frontend build
go test -race ./...
pnpm --dir frontend typecheck
pnpm --dir frontend test
```

Go 入口嵌入 `frontend/dist`，首次单独运行 Go 测试前需先构建前端。完整应用通过 Wails 启动，单独运行 Vite 不包含 Go 后端。

## 自动刷新

Go 后端统一调度，用量按 5 分钟间隔后台更新。窗口隐藏、最小化或失去焦点时继续运行。每轮自动查询及重新联网时会检查本地 CLI 账号变化，缓存尚未到期时不重复发起用量请求。额度恢复时间早于常规间隔时，会在恢复时间到达后查询服务端，不在本地将剩余额度改为 100%。

登录、用户操作或打开对话框时暂停新请求，操作结束后恢复调度。离线或查询失败时保留缓存并显示错误，等待下一周期；重新联网会唤醒调度，手动刷新可立即重新查询。自动更新通过 Wails 事件推送，保留表格和操作状态，只在“刷新”按钮显示进度，不弹出成功提示。

用户操作取消正在执行的自动用量查询，并停止批次剩余账号。HTTP 等待不占用状态锁。已发出的令牌交换继续完成并保存，避免丢失轮换后的凭据。

认证永久失效会保存重新登录状态，暂停该账号的自动请求。重新登录或同步到新凭据后恢复查询。临时网络错误保留缓存，按下一周期重试；已过期缓存单独标记，未知额度不参与剩余额度排序。

自动刷新不会在本次会话中重新加入已删除账号，也不会在整体恢复后自动合并未列入备份的原 CLI 账号。本地 CLI 切换到其他账号时仍会自动发现；手动刷新或重启可重新导入当前账号。单纯用量更新不触发 WebDAV 上传。

## 桌面体验

账号始终优先显示当前账号，可按名称或剩余额度排序，并搜索别名、邮箱或工作区。隐私开关只改变界面展示，不修改账号认证或备份内容。

当前账号不能删除。菜单与确认按钮会禁用删除操作，后端在删除前读取 CLI 实际身份再次核对，避免 CLI 切换后使用过期界面状态删除当前账号。需要先切换到其他账号，再删除原账号。

操作结果使用右下角 HeroUI Toast，成功消息显示 5 秒，切换提示和错误显示 8 秒，支持手动关闭，鼠标悬停或键盘聚焦时暂停计时。最多同时显示 3 条，对话框打开时仍可见，保存失败不会清空输入。后台错误只在新出现或内容变化时提醒，恢复后再次出现可重新提醒。窗口隐藏或切换隐私模式时清理消息，隐藏期间不积压临时提醒。认证失效、查询失败和备份冲突在账号行或设置中保留简短状态与处理入口，详细原因可悬停查看。配置加载失败保留错误和重试入口。

低额度通知在设置中开启，首次开启会请求系统通知权限。默认阈值为 10%，可选 5%、10% 或 20%。只使用当前账号成功查询的用量，每个额度窗口只提醒一次，去重记录保存在配置中。窗口隐藏后仍可通过后台查询触发通知。不为通知增加额外请求，也不自动切换账号或使用重置卡。通知内容不包含邮箱或工作区 ID。

启动时显示主窗口并注册系统图标。Windows 使用任务栏通知区域，macOS 使用菜单栏，Linux 使用支持 StatusNotifier/AppIndicator 的桌面面板托盘。托盘菜单提供“显示窗口”和“退出”，Windows 与 Linux 支持点击图标唤起，macOS 点击图标打开菜单。

点击窗口关闭按钮时保存普通窗口尺寸与位置并隐藏窗口，后台调度、认证文件监听与备份任务继续运行。托盘菜单“退出”才会停止任务并结束进程；macOS 应用菜单退出和 `⌘ + Q` 也走显式退出流程。下次启动恢复窗口状态，并按当前屏幕限制位置。再次启动会唤起已有窗口，第二个进程不会加载或修改配置。

Linux 需要桌面提供托盘宿主，部分 GNOME 环境需要安装 AppIndicator 扩展。托盘初始化或注册失败时界面明确提示，保留主窗口，此时关闭窗口会退出应用，避免隐藏后失去操作入口。

自启动注册由独立 Go 方法管理，仅作用于当前用户。Windows 使用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `Codex Deck` 项，macOS 使用 `~/Library/LaunchAgents/com.wails.codex-deck.autostart.plist`，Linux 使用 `$XDG_CONFIG_HOME/autostart/codex-deck.desktop`，未设置该变量时使用 `~/.config/autostart`。注册项是系统集成文件，不写入应用 JSON 或 WebDAV 备份，恢复备份不改变本设备自启动状态。

设置中的“开机自启动”开关默认关闭，每次打开设置时读取本设备实际注册项。开启或关闭后通过 Toast 提示，修改失败保留原状态，读取失败可重试。启用后在下次登录生效，关闭开关不退出当前进程。开关管理应用的自启动注册，系统启动设置中的额外禁用仍由系统管理。应使用正式构建并保持安装路径固定，移动程序后需关闭再开启以更新路径。

系统自启动命令带 `--autostart` 参数，主窗口保持隐藏，后台刷新与低额度通知继续运行。手动启动显示或唤起主窗口，自动启动产生的第二实例不会唤起窗口。配置读取失败或托盘不可用时显示窗口与错误。托盘“退出”结束进程，下一次登录仍按注册项启动，不配置退出后自动重启。

| 快捷键 | 操作 |
| --- | --- |
| `⌘/Ctrl + R` | 刷新 |
| `⌘/Ctrl + ,` | 设置 |
| `⌘/Ctrl + N` | 添加账号 |
| `⌘/Ctrl + F` | 搜索账号 |

打开对话框或操作进行中时暂停快捷键，输入框内不触发添加账号。

## 数据与账号切换

应用自身所有持久数据保存到 `~/.codex-deck.json`，包括账号令牌、别名、用量缓存、消费请求标识、WebDAV 配置与版本、界面偏好、通知去重记录和窗口状态。文件使用明文 JSON，包含敏感凭据。

账号切换通过写入 Codex CLI 的 `auth.json` 完成。CLI 目录由 `CODEX_HOME` 决定，未设置时使用 `~/.codex`。仅支持文件凭据存储。

```toml
cli_auth_credentials_store = "file"
```

CLI 使用其他存储方式时，应用会在切换前请求确认，再修改对应配置项。切换后需重新启动 Codex CLI。添加或删除账号不会修改 CLI 当前凭据。

启动或刷新时读取本地文件凭据，按用户与工作区身份导入新账号或更新已有账号，保留别名和用量缓存。目录监听能捕获手动 logout、login 及认证文件的原子替换，无需点击刷新。监听器只同步文件与账号状态，不额外请求用量。logout 后清除当前账号标记，已管理账号仍保留。凭据同步本身不改写 CLI 认证，数据变化后按设置自动备份；凭据未变化时不重复保存或备份。

凭据无效时显示错误，不覆盖已保存认证，仍可通过浏览器添加账号。已有账号保留比 CLI 文件更新的认证，避免覆盖尚未切换到 CLI 的重新登录结果。

令牌刷新前读取并核对 CLI 身份与凭据，写回前再次检查。CLI 同时更新认证时，应用保留其文件并显示错误。刷新令牌过期、被重复使用、失效，或刷新后仍收到 401 时，账号进入重新登录状态。

## WebDAV 备份

在设置中填写远端目录地址、用户名和密码，远端文件名固定为 `codex-deck.json`。备份包含完整配置与账号认证，使用明文 JSON，不保留历史版本。

坚果云的 `https://dav.jianguoyun.com/dav/` 是同步目录列表，不能直接存放文件。填写这个根地址时，应用自动使用 `codex-deck/codex-deck.json`，首次备份会创建 `codex-deck` 目录。填写具体目录地址或使用其他 WebDAV 服务时，文件仍直接保存在所填目录中。

账号添加、重新登录、删除、别名修改、成功切换、令牌更新和设置修改后自动备份。单纯刷新用量不触发上传，下一次备份会包含最新缓存。上传在后台串行执行，等待期间的新任务合并为最新快照，用户编辑不等待网络。失败不会撤销本地变更，可手动重试。

首次配置时，远端已有备份会暂停上传，并提示恢复或确认覆盖。已有版本通过 ETag 与 `If-Match` 条件写入保护，其他设备更新后暂停自动上传。覆盖确认也绑定版本，确认期间再次变化时拒绝写入。恢复后的版本采用实际下载结果，不沿用备份文件中的旧版本标记。

坚果云 HEAD 不返回 ETag，应用从 GET 读取其实际标签，并将原值用于 `If-Match`。实测能拒绝过期版本，但坚果云忽略 `If-None-Match: *`，两个设备同时首次创建备份时无法保证原子保护。首次配置应在一个设备完成后，再在另一个设备恢复。其他服务也需要正确执行条件头；缺少可用 ETag 时无法安全覆盖，应用会明确报错。

恢复先下载并校验备份，展示真实远端更新时间及新增、移除账号。确认后整体替换本地账号、认证和设置。取消恢复不修改本地数据。恢复不会切换 CLI 账号，也不会自动上传回远端。确认前核对远端版本，停止旧上传任务，并丢弃恢复前查询的迟到结果。

## 兼容性与验证

前端通过组件测试、类型检查和生产构建。Toast 测试覆盖自动消失、手动关闭、错误去重、隐私脱敏、隐藏时清理、保存后保留输入及加载失败后重试。使用替身 Wails 绑定在浏览器检查消息位于设置对话框上方、自动消失与手动关闭，这些检查不代表真实业务接口验证。

当前账号删除限制通过隔离 CLI 文件测试，覆盖最新身份核对、不同工作区、核对失败和前端确认期间切换。自启动注册通过隔离注册表项及临时目录测试，覆盖默认关闭、含空格路径、注册、移除、损坏条目和系统禁用标记。macOS 与 Linux 自启动模块通过交叉编译，Windows 正式程序使用隔离配置检查隐藏启动、单实例、最小化恢复、关闭驻留、显式退出及配置损坏时显示窗口。未修改用户真实自启动项，真实登录启动和 macOS、Linux 桌面行为仍需目标系统验证。

认证、用量、重置卡和 WebDAV 请求通过隔离配置与本地 HTTP 服务测试。后台调度测试覆盖无前端调用时按恢复时间查询、通知触发、暂停取消、恢复查询和退出清理。Windows 正式构建通过隔离配置与原生窗口消息检查关闭驻留、托盘唤起、单实例唤起和托盘退出清理；Linux 托盘模块通过交叉编译，桌面兼容性与 macOS 菜单栏行为仍需目标系统验证。WebDAV 另经坚果云真实服务验证上传、读取、备份解析与条件头行为，独立测试文件在验证后删除。正式备份与跨设备流程仍需在用户环境验证。真实 OpenAI 授权、服务端用量和重置卡消费尚未完成集成验证。通知规则与去重经过测试，系统权限提示和通知展示仍需在用户环境验证。

OpenAI 接口依据官方 Codex 源码实现，属于客户端内部接口，可能变化或限制第三方客户端使用。接口错误会直接显示。当前不支持 FedRAMP 工作区。
