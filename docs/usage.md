# 使用指南

本文说明当前源码的用户操作与限制。安装包能力以对应发布标签为准；字段、配置默认值和接口行为以代码定义为准，设计约束见 [架构与行为契约](architecture.md)。

## 数据位置与凭据

应用内部持久数据保存到 `~/.codex-deck.json`，包括账号令牌、缓存、设置与界面状态。文件为明文 JSON，包含敏感凭据。损坏文件会显示加载错误，不自动清空或重建账号。

CLI 目录由 `CODEX_HOME` 决定，未设置时使用 `~/.codex`。账号切换使用其中的 `auth.json`。文件凭据模式配置为：

```toml
cli_auth_credentials_store = "file"
```

CLI 使用其他存储方式时，切换前会请求确认再修改有关配置；切换后需重新启动 CLI。应用不操作系统凭据库。凭据格式与配置处理见 [`internal/deck/cli.go`](../internal/deck/cli.go)，应用状态定义与校验见 [`models.go`](../internal/deck/models.go) 和 [`storage.go`](../internal/deck/storage.go)，不建议手工拼接账号数据。

## 网络代理

设置中的“网络”支持三个代理模式。“跟随环境变量”沿用应用进程启动时的 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY` 环境变量，不读取操作系统代理或 PAC；“不使用代理”明确直连；“自定义代理”使用填写的地址和可选用户名、密码。

自定义地址例如 `http://127.0.0.1:7897`，支持 HTTP/HTTPS 代理，不支持 SOCKS。认证信息单独填写，密码使用遮罩。默认模式下的环境规则以 [Go 代理文档](https://pkg.go.dev/net/http#ProxyFromEnvironment) 为准，配置定义与校验见 [`internal/network`](../internal/network)。

“测试连接”通过当前草稿访问 GitHub API 的 HTTPS 地址，不带账号令牌，不保存配置。测试结果显示在按钮旁，修改输入后清除旧结果。点击窗口底部“保存更改”后，新请求立即采用已保存代理，无需重启；已发出的请求继续完成。连接测试失败仍可保存格式有效的配置。测试或保存失败保留输入并显示原因，自定义代理失败不会改为直连。

配置统一用于 Go 发起的认证、额度、重置卡、WebDAV、更新检查与下载。浏览器授权页仍使用浏览器自己的代理，修改此设置不会修改浏览器或系统代理。

网络配置仅本机生效，保存在应用状态文件中，不触发或参与 WebDAV 备份；恢复保留当前设备配置。代理密码同其他本地凭据一样为明文存储，不要公开分享应用配置文件。

## 本地会话浏览

顶部“账号 / 会话”切换工作区。“会话”直接读取当前 `CODEX_HOME` 下的 `sessions`，未设置时沿用 `~/.codex/sessions`，列表底部“来源”可展开查看实际目录。首次进入、搜索、筛选或点击“刷新”时读取，不实时监控文件。切回会话工作区保留已加载列表、详情与滚动位置；查看最新文件需点击“刷新”。更新期间保留已有内容，输入变化或离开工作区会取消过期请求。切换工作区保留账号搜索、设置草稿与后台调度，会话读取不请求账号服务。

列表按记录中的最近时间排序、按本地日期分组，可筛选项目和日期。每项展示标题、项目简称与时间，同名项目补充父目录；完整路径可悬停查看，也保留在详情“信息”中。搜索覆盖标题、项目及该文件中的可读请求、回复和工具内容，搜索时展示命中摘要；选择会话后定位并展开内容命中的事件。列表与详情均通过“加载更多会话”或“加载后续记录”分页，后续检索页复用当前查询结果，文件变化后旧分页失效。模型字段缺失时省略；未记录用户请求或时间时分别显示对应未知状态。

详情默认按轮次展示请求与回复。“对话 / 全部记录 / 异常”保持事件原有顺序，内容搜索命中与跳转切换到“全部记录”。同一轮中连续工具调用按组折叠，组内失败数量保持可见；展开后可查看工具名称与状态，再展开参数和关联输出，也可统一展开或折叠工具。已记录的推理摘要、压缩记录与未知事件单独折叠，不随“展开工具”展开。未知工具结果显示“状态未知”，不会自动归为成功。模型、轮数、工具次数和完整项目路径收在详情“信息”中。

点击“查找”展开会话内搜索。查找覆盖整个文件的可读记录，可通过上下匹配按钮跳到尚未加载的事件或长输出中的匹配片段；计数带 `+` 表示还有后续匹配页。“轮次”菜单也可跳到尚未加载的记录。长文本通过“上一段内容 / 下一段内容”分段查看。窄视口通过“会话列表”返回。

`Ctrl/⌘ + F` 聚焦当前工作区搜索，`Ctrl/⌘ + R` 刷新当前工作区；会话页也支持 `Ctrl/⌘ + K` 聚焦列表搜索。打开对话框或账号业务忙碌时沿用快捷键停用边界，会话页不响应添加账号快捷键。

首版支持 `sessions` 目录中的明文 rollout JSONL，按 [官方 Codex 提交 9167a0b](https://github.com/openai/codex/tree/9167a0b2d4a74d44a4d388057d304682e47313c6/codex-rs/rollout) 的持久化和 [protocol 类型](https://github.com/openai/codex/tree/9167a0b2d4a74d44a4d388057d304682e47313c6/codex-rs/protocol/src) 核对。支持会话元数据、轮次上下文、消息、函数/自定义工具调用与结果、压缩摘要，以及已支持的 `item_completed` 消息和命令事件。未支持的事件保留为未知记录并提示；加密内部思考不展示。归档目录、压缩 `.jsonl.zst`、继承历史引用及跨文件关系不合并；压缩文件和继承引用明确提示，不能把单文件记录范围声称为完整跨文件历史。

目录不存在、空目录、无搜索结果和读取失败有不同状态，错误可显式重试，筛选不会因失败清空。部分文件失败仍展示可读会话，同时在“读取提示”中列出文件与位置。末尾尚未写完的记录保留此前内容并提示刷新；已结束的坏行报告损坏。单条记录超过读取上限时明确提示该行未参与展示或检索，边界以 [`internal/sessions/reader.go`](../internal/sessions/reader.go) 为准。

会话功能只读，不编辑、删除、恢复、继续或重放记录，不读取 `history.jsonl` 作为执行轨迹，不启动 Codex。会话与检索缓存不保存到 Deck 配置，也不参与 WebDAV 备份。隐私模式隐藏已知账号身份，不能自动脱敏任意源码或秘密；正文和高亮均作为普通文本展示。

## 添加、同步与切换账号

“添加账号”启动浏览器授权，支持取消。重新登录须使用原账号与工作区，身份不匹配不会更新目标记录。当前不支持 API Key 账号和 FedRAMP 工作区。

启动、显式刷新和 CLI 认证文件变化时同步本地账号。新的用户与工作区身份会自动加入，已有身份更新凭据并保留别名、缓存。CLI 注销后清除“当前”标记，Deck 中的账号仍保留。同步本身不会切换或写入 CLI；比已保存凭据更旧的 CLI 认证不会回退已保存状态。

账号默认将“当前”置顶，可搜索别名、邮箱与工作区，或按名称、剩余额度排序。“切换”写入 CLI 文件凭据。当前账号不能删除；需要先切换到其他账号，再删除原记录。

### auth.json 导入、导出

“添加账号”旁的菜单提供“从 auth.json 导入”，使用系统文件选择框。新身份直接添加，重复身份先确认更新，保留记录 ID、别名和缓存。明确更早的刷新时间会被拒绝，确认时再次检查；取消、解析失败和保存失败不修改账号。导入只保存到 Deck，格式正确不代表服务端认证仍有效。

账号行菜单提供“导出 auth.json”。确认凭据提示后选择保存位置，默认文件名为 `auth.json`。导出只写认证字段，当前账号先同步 CLI 更新的凭据，不额外发起令牌刷新。已标记认证失效的账号需重新登录。

文件含明文登录凭据，请勿公开分享。凭据快照可能因后续刷新或撤销而失效。普通导出不改写 CLI；选择 CLI 当前认证文件时额外确认覆盖，之后需重新启动 CLI。导出不会自动改变非文件存储模式，也不能覆盖 Deck 自身配置。

## 额度、刷新与重置卡

账号表格展示 5H、Weekly 剩余额度，低于 15% 时同时标记“额度偏低”。查询时间和恢复时间显示相对时长，悬停可查看本地时区的完整时间。恢复时间已到时显示“等待确认恢复”，不会把缓存改为满额。查询失败保留缓存，未知与过期分别标记。认证永久失效提示重新登录，并暂停该账号的自动查询；网络失败不等于授权失效。

用量由 Go 后台调度，常规间隔为 5 分钟，恢复时间先到时查询服务端。隐藏、最小化或失去焦点不停止调度。账号业务操作或打开对话框会暂停自动查询，结束后恢复；账号页手动“刷新”可立即查询，前端在线事件会唤醒调度。浏览、搜索和刷新本地会话不暂停账号调度。调度规则的可执行定义见 [`automatic.go`](../internal/deck/automatic.go)。

自动调度不会立即重新加入本次会话中已删除或整体恢复移除的 CLI 账号。CLI 后来切换到另一身份时仍会发现；显式刷新或重启可重新导入实际当前账号。

通过账号菜单查看重置卡数量、状态与到期时间。使用前确认账号与消费操作。结果未确定时选择重试原请求，不能改用新请求规避不确定结果。消费结果与更新后的额度以服务端返回为准。

## WebDAV 备份与恢复

在设置的“备份”页填写远端目录地址、用户名和密码，再点击“保存更改”。远端保存一个 `codex-deck.json`，包含可跨设备恢复的应用状态和账号认证，不加密、不保留历史版本。本机网络配置不包含在备份中。恢复替换备份管理的状态，不能当作账号合并操作。

“立即备份”“恢复备份”和“覆盖远端”使用已保存配置。网络或 WebDAV 配置有未保存修改时，先保存再操作。进入恢复或覆盖确认前，其他未保存设置也需保存或明确放弃。

账号、凭据和设置变化触发自动备份，单纯刷新用量不触发上传。待上传任务合并为较新的快照，失败保留本地操作，可手动重试。首次配置已有远端备份或发现冲突时，先选择恢复或明确覆盖。

恢复先下载并展示远端更新时间以及新增、移除账号。确认前核对远端版本；取消或失败不修改本地数据。成功恢复不写 CLI、不自动上传回远端，保留本机网络配置，系统自启动注册也不改变。

### 坚果云与版本保护

使用坚果云根地址 `https://dav.jianguoyun.com/dav/` 时，应用将文件放在其 `codex-deck` 子目录；填写具体目录时使用该目录。地址处理见 [`webdav.go`](../internal/deck/webdav.go)。

已有备份使用实际 ETag 与条件写入保护。项目此前的坚果云验证发现 HEAD 不提供 ETag，GET 返回原始版本标签，且首次创建的 `If-None-Match: *` 不阻止并发创建。这是已有兼容性依据，不是服务商永久保证：首次配置应先在一个设备完成，再到另一设备恢复；服务端行为变化时需重新验证。其他 WebDAV 服务也必须正确执行条件写入，缺少有效版本标识时应用会明确提示限制。

## 桌面设置

设置窗口分为“常规”“网络”“备份”“关于”四页。设置项先编辑，点击底部“保存更改”后统一生效；切换标签页与后台状态推送保留输入。有修改的标签页显示圆点。关闭窗口、按 Esc 或点击遮罩时，未保存修改需要明确放弃。

本地配置一次保存，校验失败会定位对应页，写入失败保留原配置。开机自启动通过独立系统接口修改；本地配置成功而自启动失败时，显示部分成功原因并保留自启动修改，重试只处理待保存项。

启动时显示主窗口并驻留托盘或菜单栏。关闭窗口后后台任务继续运行，通过托盘“显示窗口”唤起、“退出”结束；macOS 应用菜单退出和 `⌘ + Q` 同样显式退出。再次手动启动会唤起已有实例。托盘失败时保留错误和窗口，关闭窗口会退出。

Linux 需要桌面提供 StatusNotifier/AppIndicator 托盘宿主，部分 GNOME 环境需配置相应扩展。桌面与通知支持还取决于目标系统环境。

“开机自启动”默认关闭，在“常规”页编辑，作用于当前用户登录桌面的启动过程。每次打开设置读取本设备注册项；保存启用后隐藏启动，后台刷新与通知继续工作，手动启动仍显示窗口。系统额外禁用由系统管理，恢复 WebDAV 备份不会改变注册。保持安装路径固定，移动程序后关闭并保存，再开启并保存，以更新路径。注册位置与系统行为以 [`internal/autostart`](../internal/autostart) 为准。

“低额度通知”默认关闭，在“常规”页编辑，首次保存启用时请求系统通知权限。默认阈值为 10%，可选 5%、10%、20%。只对实际当前账号的成功查询判断，同一额度窗口不重复提醒；不增加查询、不切换账号、不消费卡片。有效默认值和去重规则见 [`notifications.go`](../internal/deck/notifications.go)。

隐私模式隐藏邮箱和工作区，包括消息、确认预览与可访问性文字，但不改变凭据或备份。操作结果通过短暂消息显示，后台错误去重，窗口隐藏时不积压消息；需要处理的问题仍有状态与入口。

| 快捷键 | 操作 |
| --- | --- |
| `⌘/Ctrl + R` | 刷新当前工作区 |
| `⌘/Ctrl + ,` | 设置 |
| `⌘/Ctrl + N` | 账号工作区中通过浏览器添加账号 |
| `⌘/Ctrl + F` | 搜索当前工作区 |
| `⌘/Ctrl + K` | 会话工作区中搜索会话 |

对话框打开或操作进行中停用快捷键，输入框内不触发添加账号。

## 程序更新

主窗口显示版本，设置的“关于”页可查看与复制构建提交号、手动检查更新或关闭自动检查。自动检查开关点击“保存更改”后生效。手动检查与安装使用已保存代理，网络配置有未保存修改时需先保存；进入安装确认前，其他未保存设置也需保存或明确放弃。正式发布包启动后在后台定期检查，只接收本项目正式 Release；开发构建不自动检查或安装。具体调度和构建标记以 [`app.go`](../app.go) 和 [`version.go`](../version.go) 为准。

发现更新时不主动唤起隐藏窗口，已有对话框时等待操作结束，同一版本每次运行只自动提醒一次。确认后下载，下载期间可取消；完成后通过辅助进程退出、替换并重启。安装位置需可写。下载失败不退出，替换失败会尝试恢复旧程序；更新错误可在设置中查看，也可从发布说明手动下载。

真实升级仍受系统签名、权限和运行库影响。macOS 未签名包可能被系统拦截，构建成功不代表已签名或公证。部署条件与验证范围见 [开发与发布](development.md)。
