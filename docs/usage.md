# 使用指南

本文说明当前源码的用户操作与限制。安装包能力以对应发布标签为准；字段、配置默认值和接口行为以代码定义为准，设计约束见 [架构与行为契约](architecture.md)。

## 数据位置与凭据

应用内部持久数据保存到 `~/.codex-deck.json`，包括账号令牌、缓存、设置与界面状态。文件为明文 JSON，包含敏感凭据。损坏文件会显示加载错误，不自动清空或重建账号。

CLI 目录由 `CODEX_HOME` 决定，未设置时使用 `~/.codex`。账号切换使用其中的 `auth.json`。文件凭据模式配置为：

```toml
cli_auth_credentials_store = "file"
```

CLI 使用其他存储方式时，切换前会请求确认再修改有关配置；切换后需重新启动 CLI。应用不操作系统凭据库。凭据格式与配置处理见 [`internal/deck/cli.go`](../internal/deck/cli.go)，应用状态定义与校验见 [`models.go`](../internal/deck/models.go) 和 [`storage.go`](../internal/deck/storage.go)，不建议手工拼接账号数据。

## 添加、同步与切换账号

“添加账号”启动浏览器授权，支持取消。重新登录须使用原账号与工作区，身份不匹配不会更新目标记录。当前不支持 API Key 账号和 FedRAMP 工作区。

启动、显式刷新和 CLI 认证文件变化时同步本地账号。新的用户与工作区身份会自动加入，已有身份更新凭据并保留别名、缓存。CLI 注销后清除“当前”标记，Deck 中的账号仍保留。同步本身不会切换或写入 CLI；比已保存凭据更旧的 CLI 认证不会回退已保存状态。

账号默认将“当前”置顶，可搜索别名、邮箱与工作区，或按名称、剩余额度排序。“切换”写入 CLI 文件凭据。当前账号不能删除；需要先切换到其他账号，再删除原记录。

### auth.json 导入、导出

“添加账号”旁的菜单提供“从 auth.json 导入”，使用系统文件选择框。新身份直接添加，重复身份先确认更新，保留记录 ID、别名和缓存。明确更早的刷新时间会被拒绝，确认时再次检查；取消、解析失败和保存失败不修改账号。导入只保存到 Deck，格式正确不代表服务端认证仍有效。

账号行菜单提供“导出 auth.json”。确认凭据提示后选择保存位置，默认文件名为 `auth.json`。导出只写认证字段，当前账号先同步 CLI 更新的凭据，不额外发起令牌刷新。已标记认证失效的账号需重新登录。

文件含明文登录凭据，请勿公开分享。凭据快照可能因后续刷新或撤销而失效。普通导出不改写 CLI；选择 CLI 当前认证文件时额外确认覆盖，之后需重新启动 CLI。导出不会自动改变非文件存储模式，也不能覆盖 Deck 自身配置。

## 额度、刷新与重置卡

账号表格展示 5H、Weekly 剩余额度，恢复时间使用本地时区。查询失败保留缓存，未知与过期分别标记。认证永久失效提示重新登录，并暂停该账号的自动查询；网络失败不等于授权失效。

用量由 Go 后台调度，常规间隔为 5 分钟，恢复时间先到时查询服务端。隐藏、最小化或失去焦点不停止调度。用户操作或打开对话框会暂停自动查询，结束后恢复；手动“刷新”可立即查询，前端在线事件会唤醒调度。调度规则的可执行定义见 [`automatic.go`](../internal/deck/automatic.go)。

自动调度不会立即重新加入本次会话中已删除或整体恢复移除的 CLI 账号。CLI 后来切换到另一身份时仍会发现；显式刷新或重启可重新导入实际当前账号。

通过账号菜单查看重置卡数量、状态与到期时间。使用前确认账号与消费操作。结果未确定时选择重试原请求，不能改用新请求规避不确定结果。消费结果与更新后的额度以服务端返回为准。

## WebDAV 备份与恢复

在设置中填写远端目录地址、用户名和密码。远端保存一个 `codex-deck.json`，包含应用配置和账号认证，不加密、不保留历史版本。恢复会整体替换本地状态，不能当作账号合并操作。

账号、凭据和设置变化触发自动备份，单纯刷新用量不触发上传。待上传任务合并为较新的快照，失败保留本地操作，可手动重试。首次配置已有远端备份或发现冲突时，先选择恢复或明确覆盖。

恢复先下载并展示远端更新时间以及新增、移除账号。确认前核对远端版本；取消或失败不修改本地数据。成功恢复不写 CLI、不自动上传回远端，系统自启动注册也不改变。

### 坚果云与版本保护

使用坚果云根地址 `https://dav.jianguoyun.com/dav/` 时，应用将文件放在其 `codex-deck` 子目录；填写具体目录时使用该目录。地址处理见 [`webdav.go`](../internal/deck/webdav.go)。

已有备份使用实际 ETag 与条件写入保护。项目此前的坚果云验证发现 HEAD 不提供 ETag，GET 返回原始版本标签，且首次创建的 `If-None-Match: *` 不阻止并发创建。这是已有兼容性依据，不是服务商永久保证：首次配置应先在一个设备完成，再到另一设备恢复；服务端行为变化时需重新验证。其他 WebDAV 服务也必须正确执行条件写入，缺少有效版本标识时应用会明确提示限制。

## 桌面设置

启动时显示主窗口并驻留托盘或菜单栏。关闭窗口后后台任务继续运行，通过托盘“显示窗口”唤起、“退出”结束；macOS 应用菜单退出和 `⌘ + Q` 同样显式退出。再次手动启动会唤起已有实例。托盘失败时保留错误和窗口，关闭窗口会退出。

Linux 需要桌面提供 StatusNotifier/AppIndicator 托盘宿主，部分 GNOME 环境需配置相应扩展。桌面与通知支持还取决于目标系统环境。

“开机自启动”默认关闭，作用于当前用户登录桌面的启动过程。每次打开设置读取本设备注册项；启用后隐藏启动，后台刷新与通知继续工作，手动启动仍显示窗口。系统额外禁用由系统管理，恢复 WebDAV 备份不会改变注册。保持安装路径固定，移动程序后关闭再开启以更新路径。注册位置与系统行为以 [`internal/autostart`](../internal/autostart) 为准。

“低额度通知”默认关闭，首次开启请求系统通知权限。默认阈值为 10%，设置中可选 5%、10%、20%。只对实际当前账号的成功查询判断，同一额度窗口不重复提醒；不增加查询、不切换账号、不消费卡片。有效默认值和去重规则见 [`notifications.go`](../internal/deck/notifications.go)。

隐私模式隐藏邮箱和工作区，包括消息、确认预览与可访问性文字，但不改变凭据或备份。操作结果通过短暂消息显示，后台错误去重，窗口隐藏时不积压消息；需要处理的问题仍有状态与入口。

| 快捷键 | 操作 |
| --- | --- |
| `⌘/Ctrl + R` | 刷新 |
| `⌘/Ctrl + ,` | 设置 |
| `⌘/Ctrl + N` | 浏览器添加账号 |
| `⌘/Ctrl + F` | 搜索账号 |

对话框打开或操作进行中停用快捷键，输入框内不触发添加账号。

## 程序更新

主窗口显示版本，设置中可查看与复制构建提交号、手动检查更新或关闭自动检查。正式发布包启动后在后台定期检查，只接收本项目正式 Release；开发构建不自动检查或安装。具体调度和构建标记以 [`app.go`](../app.go) 和 [`version.go`](../version.go) 为准。

发现更新时不主动唤起隐藏窗口，已有对话框时等待操作结束，同一版本每次运行只自动提醒一次。确认后下载，下载期间可取消；完成后通过辅助进程退出、替换并重启。安装位置需可写。下载失败不退出，替换失败会尝试恢复旧程序；更新错误可在设置中查看，也可从发布说明手动下载。

真实升级仍受系统签名、权限和运行库影响。macOS 未签名包可能被系统拦截，构建成功不代表已签名或公证。部署条件与验证范围见 [开发与发布](development.md)。
