# 架构与行为契约

本文记录设计意图、长期约束和行为边界，是架构决策的事实来源。具体实现、字段与默认值以代码和测试为准。发现实现偏离时，应判断并解决冲突，不能只把本文改成代码现状。

## 职责与信任边界

应用使用 Go、Wails 与 React。Go 持有凭据、执行业务 HTTP、持久化状态并与操作系统交互；前端通过 Wails 接收展示信息和发起用户操作。后台任务不能依赖窗口是否显示或 WebView 是否活跃，否则托盘驻留时会丢失刷新与通知能力。

账号状态由本应用独立维护。可以交换标准 CLI 凭据文件，但不读取其他管理工具的数据格式，不通过 codex、app-server、curl 等子进程代办业务请求。这避免把业务能力绑定到外部工具的数据和进程生命周期，网络边界也能独立验证。更新辅助进程属于程序安装流程，不承担账号或接口业务。

认证和后台接口以 [官方 Codex 源码](https://github.com/openai/codex) 为依据。内部接口不是稳定公共 API，必须核对实际协议并暴露不兼容错误，不能自行伪造成功结果。

## 状态与存储

应用内部持久状态集中在一个明文 JSON 文件中，便于检查、迁移和整体恢复。账号、缓存、界面偏好、通知去重和备份版本共同组成应用状态；系统凭据库、数据库、加密层、额外持久备份与日志不属于当前设计。自有 JSON 字段使用英文小写下划线命名。文件位置与用户配置见 [使用指南](usage.md)。

CLI 集成文件、自启动注册项、用户主动导出的凭据，以及安装更新的临时文件，属于明确的外部边界，不应再成为应用状态的第二份真相。自启动反映本设备实际注册，不能由恢复的账号备份伪造。

本机网络配置保存在同一应用状态文件中，但不参与 WebDAV 上传，恢复时保留本机值。代理地址、监听端口和认证可能只适用于当前设备，不能随账号恢复覆盖另一设备的网络条件。

Codex CLI 代理以当前 CLI 目录中的 `.env` 为唯一事实来源，不在 Deck 配置中保存副本，也不参与备份和恢复。只修改 HTTP/HTTPS 代理字段，保留其他变量与注释；保存前核对代理字段是否被外部修改，并基于最新文件编辑。CLI 文件写入与 Deck 设置分别保存并报告结果，避免一处失败被误报为全部成功。代理读取按需执行，不加载文件中的变量到 Deck 进程，也不把其他变量传给前端。

本地 Codex 会话是外部只读数据源，复用 CLI 根目录解析结果，读取其中的 `sessions`。会话、全文检索结果和分页状态只在内存中，不进入 Deck 的持久状态、状态广播或 WebDAV 快照，也不归属到当前 Deck 账号。读取接口只接受后端枚举的会话 ID，拒绝目录中的链接和越界路径；不启动 CLI，不读取会话引用的其他文件，不执行记录内容。

数据变更串行保存，以临时文件替换目标文件并清理临时文件。保存失败不接受半份新状态；损坏配置报错，不静默重建、清空账号或用默认假数据替代。错误应可见，网络失败不撤销已经成功保存的本地操作。

## 账号身份与 CLI 集成

- 账号按稳定用户与工作区身份去重，不能只凭邮箱合并。重新登录目标身份不匹配时拒绝更新。
- 浏览器登录采用授权码与 PKCE。取消登录应关闭回调监听。账号令牌留在 Go，前端只接收必要展示信息与确认标识。
- 添加和导入账号只保存到本应用；删除前确认，只移除本地记录，不撤销授权、不删除 CLI 凭据、不自动切换其他账号。CLI 实际当前账号不能删除，提交操作时必须重新核对。
- 当前标记来自 CLI 实际文件认证，不来自上次点击记录。切换仅通过文件凭据完成；改变非文件存储方式需明确确认，只修改有关配置，保留其他内容。集成路径尊重 CLI 环境配置，不写死用户目录，不管理 CLI 进程。
- 凭据同步不写回 CLI。不同凭据仅在双方刷新时间有效且 CLI 时间严格更新时自动采用；时间相同或缺失不能证明先后，保留 Deck 凭据，避免覆盖主动登录、导入或恢复结果。令牌相同只采用较晚的已知刷新时间，不清除认证失效。启动、文件监听、查询与导出使用相同规则。
- 令牌刷新仅在 CLI 与本次实际使用的凭据一致时安排写回，写回前再次核对令牌与刷新时间。身份相同不代表凭据相同，不能因此覆盖 CLI 中另一份登录凭据；刷新期间 CLI 变化时保留文件并报告结果已保存到 Deck。
- 文件导入校验身份与必要令牌。相同凭据直接结束，不改写记录或触发备份；不同凭据须确认后更新，保留记录身份、别名和有效缓存。双方时间有效且导入时间更早时拒绝覆盖，时间相同或缺失允许用户确认，提交时再次核对。解析身份元数据不是服务端认证验证。
- 导出复用 CLI 认证格式，只包含凭据，不混入应用设置。写入当前 CLI 认证文件需额外确认，应用自己的状态文件不得作为导出目标。
- 永久认证失效保存为需要重新登录的状态并暂停自动请求；新登录或新凭据清除失效状态。临时网络错误不能据此判定授权撤销。

## 后台请求与并发

认证、额度、重置卡、WebDAV 和程序更新共用 Go 代理路由。默认模式沿用代理环境变量，直连模式忽略这些变量，自定义模式使用明确配置的 HTTP/HTTPS 代理；不读取系统代理或 PAC，也不因代理失败静默直连。外部浏览器的网络设置不由应用代理控制。

代理变更先校验并成功保存，再对新请求生效。已发出的请求继续使用原传输，不能为热切换中断令牌交换。连接测试使用待保存配置与不带账号令牌的 HTTPS 请求，不改变已保存路由。

后台调度负责缓存周期与额度恢复时间。额度恢复必须再次查询服务端，不能把本地缓存直接改为满额；窗口隐藏后仍继续调度。CLI 目录监听只同步本地状态，不额外请求用量，并需捕获认证文件的原子替换。

账号业务操作或对话框暂停新的自动查询，并取消可中断的自动用量请求。已发出的令牌交换继续完成并保存，避免丢失轮换后的凭据。网络等待不占用账号状态锁，状态推送不关闭对话框或重置用户草稿。

会话枚举、解析、内容检索与详情读取使用独立服务，不占用账号状态锁，不调用账号刷新或暂停自动调度。首次进入会话工作区、筛选、搜索与显式刷新才读取文件，不增加常驻监听或后台扫描。列表摘要、详情索引与检索结果分开缓存，按文件身份、大小和修改时间失效；搜索不淘汰详情索引，同一查询的后续分页复用检索结果。文件读取不占用共享缓存锁，列表、详情与会话内查找分别取消过期请求，应用退出统一取消。详情事件和长文本分段传给 WebView，查找覆盖该文件的全部可读记录。未完成尾行与坏行分别报告，未知事件、读取上限与部分文件失败不能静默跳过；支持范围见使用指南。

恢复后与删除后保留用户选择的账号范围，自动调度不能立即重新加入已移除账号。恢复时记录 CLI 实际身份，避免尚未处理的文件监听事件重新导入恢复移除的账号。显式刷新、重启与后来切换到另一 CLI 身份的操作边界见使用指南。

用量按窗口时长识别并展示剩余比例。失败保留有效缓存和查询时间；缺失窗口或卡片数量显示未知，未知与过期明确区分，不能把未知额度排序为满额。单账号失败不应阻止其他账号查询。

重置卡消费须确认账号与操作，请求标识持久保存。结果未确定时沿用原标识，不能因重试消费另一张卡。区分服务端结果，消费后重新查询，不在本地伪造额度。

## WebDAV 与整体恢复

远端只维护一个明文配置快照，不加密、压缩或保留历史版本。账号、凭据和设置的语义变化触发自动备份；单纯缓存刷新不触发上传，备份状态变化也不产生备份循环。

上传串行执行，合并等待期间的旧快照，网络不阻塞用户编辑。失败不撤销本地变更，不增加后台自动重试。首次配置已有远端备份或版本冲突时暂停上传，由用户选择恢复或明确覆盖。

覆盖保护必须使用服务端实际版本与 HTTP 条件写入。先读取再盲写不具备跨设备并发保护，不能编造 ETag。服务端无法提供所需语义时，应暴露限制，不能声称安全覆盖；坚果云的已知约束见 [使用指南](usage.md)。

恢复先下载、校验并展示真实远端更新时间和账号差异，确认时再次核对远端版本。取消或失败不改变本地数据。成功后整体替换备份管理的状态，保留本机网络配置，不合并账号、不写 CLI、不自动回传；恢复前的上传、查询或确认结果不得改写新状态。

## 桌面与展示

单主窗口，通过顶部“账号 / 会话”切换工作区，没有全应用常驻侧边栏，设置采用对话框。账号工作区以表格为主体；会话工作区采用左列表、右详情，窄视口切换列表与详情。这样给本地历史浏览足够阅读空间，同时保持账号操作的简单结构。工作区切换保留账号控制器、订阅和草稿；搜索、刷新快捷键路由到当前工作区，会话页不触发添加账号。

使用 HeroUI 与 Tailwind，主题跟随系统，优先清楚间距、中性色、小圆角和少量强调色，尽量不用分隔线。不添加装饰背景、营销文案、无关动画、欢迎语、功能介绍、统计卡片或常驻操作说明。字段标签、错误、进度、空状态和确认文字保持简短。套餐来自认证或服务端，不提供手动编辑。

设置按常规、网络、备份、关于分组，草稿由窗口统一持有，保存入口覆盖所有标签页，避免局部保存被误认为全部保存。网络、WebDAV 与设置页偏好一次写入本地状态，保留账号、隐私及排序等其他状态；成功写入后才切换代理和安排必要的备份。系统自启动独立修改，部分失败明确显示已保存范围，不能声称全部成功。切换标签页和后台推送不覆盖草稿，离开窗口或进入其他确认流程前需处理未保存修改。

隐私模式只影响展示，需覆盖邮箱、工作区、消息、恢复与导入导出预览，以及可访问性标签。常规操作成功由更新后的界面反馈，不额外弹出确认；复制、CLI 重启要求和消费结果保留必要消息。后台错误保留简短状态和入口，不同时弹出消息；设置保存与连接测试错误在操作位置展示。窗口隐藏时不积压临时消息，保存失败不清空输入。

会话工作区默认展示对话，工具过程、记录摘要与完整元数据按需展开，让阅读空间优先留给请求和回复。内容搜索命中可切换到全部记录并展开目标；折叠不改变搜索范围，不删除或静默忽略未知事件与读取问题。会话标题、项目、匹配摘要、正文、工具输出和错误沿用已知账号身份的展示隐藏规则，高亮在隐藏之后生成，并用普通 React 文本与 `pre` 展示。隐私模式不保证自动识别任意源码或秘密。工具成功、失败只根据记录中的明确状态判断，缺失状态保留未知；模型、日期与轮次不填演示默认值，也不把 token 数换算成额度或费用。

单实例避免并行修改同一份状态。正常关闭保存窗口状态并隐藏，显式退出结束后台任务；托盘不可用时保留窗口和错误，关闭应能退出，避免用户失去入口。系统自启动仅作用于当前用户，隐藏启动与手动启动有不同的唤起意图。

表格警示色、额度不足筛选与通知共用低额度阈值，边界包含等于阈值。低额度通知默认关闭，仅在当前账号成功查询后判断，按额度窗口去重并持久保存。通知不包含账号身份，不增加查询、不自动切换、不消费重置卡。

## 发布与程序更新

应用版本、系统版本信息、发布标签与附件应一致，具体定义与发布操作见 [开发与发布](development.md)。发布任务应在全部目标构建完成后公开完整 Release，避免客户端发现缺少本平台安装包的版本。

自动检查与账号刷新是独立任务，发现新版本只标记设置入口，不自动打开对话框，避免打断当前操作。安装须由用户主动打开更新并确认，开发构建不能自动替换自身。只安装本项目正式发布中匹配平台的附件；下载失败不退出，下载阶段允许取消。

安装辅助进程等待旧程序完成退出后替换，再启动新版本。更新不改变账号数据、CLI 凭据或自启动路径，替换失败应尽量恢复原程序并暴露错误。能启动子进程不等于新程序已成功运行，实际恢复与重启能力须在目标平台验证。签名、系统安装权限和运行库属于真实部署条件，不能由本地测试代替。
